# Email & username validation

`auth/email` and `auth/username` validate and normalize user input into a
canonical form before you store it. Each module has its own page:

| Module | Page |
|---|---|
| `auth/email` | [Email validation](../modules/email.md) |
| `auth/username` | [Username validation](../modules/username.md) |

See also the [error reference](../reference/errors.md) and the runnable
[email](../../examples/modules/email/) and
[username](../../examples/modules/username/) examples.
